# 🌟 Habit Tracker PWA

A modern **Progressive Web App (PWA)** built with **React + TypeScript + Vite** to help you build and maintain habits consistently. 🚀  

---

## ✨ Features
- 📅 Track daily habits with ease  
- 📊 Visualize progress with charts  
- 🔔 Custom reminders & notifications  
- 📱 Works offline (PWA support)  
- 🎨 Clean and responsive UI  

---

## 🛠️ Tech Stack
- ⚛️ React  
- 🌀 Vite  
- 🔒 TypeScript  
- ✅ ESLint + Prettier
